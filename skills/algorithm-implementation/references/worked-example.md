# 可运行示范：非负整数权最短路

scripts/verify_shortest_paths.py 使用标准库和固定种子，构造小规模有向多重图，比较堆版 Dijkstra 与独立分轮松弛基线。包含无边、零权环、重边、自环、大整数及负权拒绝。

契约：顶点为0到n-1，n至少1；权重为非负整数；输出源点到全部点的距离，不可达为 math.inf。这里只返回距离，不恢复路径。

正确性要点：非负权下，最小暂定距离的有效出堆点不会被经由更远未处理点的路径缩短；松弛保持已知路径长度上界。代码跳过过期堆项。参考实现每轮使用上一轮快照，覆盖增加一条边的候选路径；简单最短路径无需超过n-1条边。

以n顶点、m边计，示范堆实现时间可记为 O(n + m log(m+2))，辅助存储 O(n+m)，包含邻接表和过期堆项；该记法在允许重边时不把m无条件当n的平方以内。整数算术成本另随位长增长。基线做至多n-1轮、每轮复制n个值并扫m条边，时间 O(n(n+m))，除输入外辅助空间 O(n)。

对拍只提供被测有限案例的一致性证据，不能证明所有输入、负权算法、浮点行为或生产性能。脚本不读取外部模块、不安装依赖、不写业务文件。迁移到其他算法时必须重新设计契约、独立oracle与边界，不能只替换函数名。
