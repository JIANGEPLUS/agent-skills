# algorithm-implementation — 实现、测试与性能

---

## 1. 简介

算法技能包的一个模块，负责**把已定方案落地为可运行、可复现、可度量的实现**。可独立调用，也可由 `algorithm-engineer` 总纲路由而来。

---

## 2. 职责边界

| 做什么 | 不做什么 |
|--------|---------|
| 代码契约、分层验证、对拍与 oracle 设计、profiler 优化、可复现性能记录 | 算法选型（→ `algorithm-modeling`）、正确性证明（→ `algorithm-proof`）、模型训练与调参（→ `algorithm-applied`） |

---

## 3. 触发条件

写算法代码 / 单元测试 / 随机对拍 / 暴力基线验证 / 边界用例 / 浮点容差 / profiler 热点 / 性能回归 / benchmark 记录 / 运行示范脚本。

---

## 4. 输入

已定算法方案（描述或伪代码）；可选：目标语言与版本、接口约定、测试规模与预算。

---

## 5. 分层验证

1. **样例与手工可算案例**：核对输出定义
2. **边界**：空/单元素、重复、全相等、极值、无解、多解、不可达、零/负值、退化结构
3. **小规模独立基线对拍**：有界输入、固定种子、保留失败输入；不复制候选逻辑当 oracle
4. **性质/变形测试**：只用已证明适用的性质；多解检查合法性与目标值，不强制相同排列
5. **压力测试**：隔离生产，限制输入/时间/内存；避免指数基线跑大输入

---

## 6. 输出

- 代码与运行方式（命令、依赖、版本）
- 验证层级与结果（样例 / 边界 / 对拍 / 性质 / 压力）
- 性能记录（口径、分布、内存、结论适用范围）
- 残留风险与未验证项

---

## 7. 使用要点

- 语种差异要落实：C++ 溢出与迭代器、Java 数值与比较器、Python 递归深度/切片复制/大整数
- 测试不能证明全输入正确；浮点对拍需有根据的容差与误差尺度
- 性能结论只支持被测配置与输入；记录分布而非最好一次
- 环境缺失时标注"未运行"，不伪称 AC 或跑分通过
- 示范脚本只覆盖自身契约，迁移到其他算法须重新设计契约与 oracle
