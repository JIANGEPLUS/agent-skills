# fundamentals-analysis — 基本面与盈利分析

---

## 1. 简介

股票研究技能包的一个模块，负责**公司基本面认知与盈利事件解读**。可独立调用，也可由 `equity-research` 总纲路由而来。

---

## 2. 职责边界

| 做什么 | 不做什么 |
|--------|---------|
| 公司速览卡、业绩前瞻、业绩深度解读、估计与模型更新 | 估值建模（→ `valuation`）、撰写正式报告（→ `research-report`）、仓位与止损（→ `risk-monitoring`） |

---

## 3. 触发条件

公司速览 / tearsheet / 财报分析 / 业绩前瞻 / 季报解读 / 业绩点评 / 模型更新 / 更新预测 / earnings analysis / earnings preview。

---

## 4. 输入

公司名或代码；报告季度（可选，缺省按当前日期推断最新报告期）；已有的财务模型（模型更新场景）。

---

## 5. 三种交付形态

| 形态 | 触发场景 | 产出 |
|------|---------|------|
| 公司速览卡 | 快速了解一家公司 | 一页纸：业务、关键财务、估值、股东、催化与风险 |
| 业绩前瞻 Preview | 业绩尚未发布 | 共识表 + 观测框架 + 牛/基/熊情景 + 催化清单 |
| 业绩深度 Analysis | 业绩已发布（3 个月内） | Beat/Miss、分部拆解、估计修正、论点影响、目标价影响 |
| 模型更新 | 新实际值/指引/宏观变化 | 实际 vs 估计表、前瞻估计修正、估值影响、评级结论 |

---

## 6. 使用要点

- 先按当前日期确认"能拿到的最新一期财报"再取数（A 股/美股/港股披露节奏不同）
- 每个数字标注来源与报告期；缺失 `[MISSING]`，超 90 天 `[STALE]`
- 区分一次性项目与可持续趋势；区分 GAAP 与调整后口径
- 更新估计后与 Street 共识对比，注意股份数变化对 EPS 的影响
