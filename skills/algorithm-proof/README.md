# algorithm-proof — 正确性与复杂度

---

## 1. 简介

算法技能包的一个模块，负责**为方案提供"凭什么对"与"代价是多少"的严谨账本**。可独立调用，也可由 `algorithm-engineer` 总纲路由而来。

---

## 2. 职责边界

| 做什么 | 不做什么 |
|--------|---------|
| 正确性证明义务落实、复杂度账本、保证范围界定（精确/近似/概率/启发式） | 算法选型（→ `algorithm-modeling`）、实测跑分与 profiler（→ `algorithm-implementation`）、领域前提核查（→ `algorithm-domain-checks`） |

---

## 3. 触发条件

证明正确性 / 为什么对 / 复杂度多少 / 最坏·均摊·期望 / 空间复杂度 / 是否全局最优 / 近似比与概率保证 / 伪多项式判定 / 递归栈与复制开销。

---

## 4. 输入

已选定的算法方案（描述或代码）；可选：输入参数定义、约束、目标性质。

---

## 5. 工作流

1. 明确要证明什么：终止性、最优性、覆盖性、等价性、保证边界
2. 按类型落实证明义务（循环不变式 / DP 状态语义 / 贪心交换论证 / 搜索覆盖 / 归约 / 近似与随机保证）
3. 无法证明的部分显式列出并尝试构造反例
4. 建立复杂度账本：参数与计算模型 → 预处理 / 单次操作 / 总操作数 / 输出大小
5. 区分最坏 / 均摊 / 期望，注明随机性或分布假设
6. 输出保证范围与残留风险

---

## 6. 输出

- 结论与适用前提
- 正确性依据（分条标明类型）与**未证明部分**
- 复杂度账本（参数定义、时间、空间、假设）
- 保证范围（精确 / 近似 / 概率 / 启发式）与残留风险

---

## 7. 使用要点

- 不用强行制造形式证明；不确定部分显式列出并尝试反例
- 测试通过不能替代证明；未证明就不声称全局最优
- 均摊不是"随机平均"；辅助空间与输入/输出空间分开统计
- 渐近符号不能说明墙钟时间，不宣称固定规模必能一秒通过
