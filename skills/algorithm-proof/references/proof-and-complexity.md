# 正确性与复杂度

## 证明义务

- 循环：初始化成立→每轮保持→终止时得到要求，并说明为何终止。
- DP：定义状态语义、基本情形、合法且完整的转移、计算顺序、最终答案位置；空间压缩检查是否覆盖仍需使用的旧值。
- 贪心：证明局部选择可扩展为最优，不能以“直觉最划算”代替论证。
- 搜索：证明状态覆盖与剪枝不会删除需要的解，处理重复状态及环。
- 归约：说明映射方向、构造代价、解可转换性；无法证明归约就不要宣称问题难度等价。
- 近似/随机：给出适用条件、保证定义、失败概率或未有保证；单次实验不是概率证明。

不用强行制造形式证明；不确定部分显式列出并尝试反例。

## 复杂度账本

定义输入参数和计算模型。分别统计预处理、单次操作、总操作数及输出大小。
最坏、均摊、期望不是同义词；均摊不是“随机平均”。注明随机性或分布假设。
辅助空间与输入/输出空间分开；递归栈、对象开销、复制和缓存不能漏算。
整数数值范围也是约束；以容量值为维度的 DP 需检查其与编码位长关系。
渐近符号不能说明墙钟时间：常数、局部性、语言对象、I/O、并发和数据分布可能主导工程表现。
不要宣称某固定规模必能一秒通过，除非测量同一评测环境。
