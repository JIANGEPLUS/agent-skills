# valuation — 估值测算

股票研究技能包的一个模块，负责**从财务建模到目标价推导**的完整估值链条。可独立调用，也可由 `equity-research` 总纲路由而来。

## 职责边界

| 做什么 | 不做什么 |
|--------|---------|
| 三表联动建模、WACC、DCF、可比估值、敏感性/情景、目标价推导 | 业绩点评（→ `fundamentals-analysis`）、报告撰写（→ `research-report`）、仓位管理（→ `risk-monitoring`） |

## 触发条件

DCF / 现金流折现 / WACC / 财务建模 / 三表模型 / 可比估值 / comps / 相对估值 / 敏感性分析 / 情景分析 / 目标价推导。

## 输入

公司名或代码；历史财报（或用户提供的财务数据）；可选：可比公司清单、目标倍数、用户指定的假设。

## 工作流

1. **收入驱动拆解**：量×价 / 用户×ARPU / 门店×坪效，3-5 年预测框架
2. **三表联动建模**：利润表 → 资产负债表 → 现金流量表，必须闭合（资产=负债+权益）
3. **WACC 与 DCF**：Ke = Rf + β×ERP；Kd×(1−T)；FCFF/FCFE；终值永续增长或退出倍数
4. **可比估值**：5-10 家 comp，历史与前瞻倍数，均值/中位数/分位，隐含溢折价
5. **敏感性与情景**：WACC×永续增速（或收入增速×利润率）5×5 矩阵；牛/基/熊；终值占比 >75% 警示
6. **目标价推导**：DCF 与 Comps 加权 → 目标价 → 相对现价空间 → 评级含义

## 输出

假设表（每项标注来源/依据）| DCF 估值总结（三情景 + 终值占比）| Comp 表 | 敏感性矩阵 | 目标价与评级含义

## 使用要点

- 永续增长率通常不超过 GDP 增速；WACC 各组成部分须有来源
- 周期性行业用中周期正常化盈利；亏损公司改用 EV/Revenue 或 P/S
- 注意会计准则差异（IFRS / GAAP / 中国准则）；高增长溢价需量化
- 所有假设区分"事实数据"与"分析师判断"
