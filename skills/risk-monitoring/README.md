# risk-monitoring — 风险与论点跟踪

---

## 1. 简介

股票研究技能包的一个模块，负责**把投资论点翻译成可执行的仓位规则与持续跟踪机制**。可独立调用，也可由 `equity-research` 总纲路由而来。

---

## 2. 职责边界

| 做什么 | 不做什么 |
|--------|---------|
| 仓位测算、对冲设计、监控/止损规则、论点记分卡、催化剂日历、事件情景分析 | 重算估值（引用 `valuation` 结果）、撰写推介（→ `research-report`）、筛选新标的（→ `idea-screening`） |

---

## 3. 触发条件

仓位管理 / position sizing / 对冲 / hedge / 止损 / 风险管理 / 论点跟踪 / thesis check / 催化剂日历 / 事件分析 / 情景分析 / "如果…会怎样"。

---

## 4. 四块能力

| 能力 | 产出 |
|------|------|
| 仓位与对冲 | 最紧约束下的仓位%、对冲工具与成本、净敞口、监控规则表、退出计划 |
| 论点跟踪 | 论点记分卡（支柱/预期/状态/趋势）、更新日志、信心水平 |
| 催化剂日历 | 财报/公司行动/行业/宏观事件日历 + 周度前瞻 + 仓位含义 |
| 事件情景分析 | 事件影响评估卡（概率加权）、双变量敏感性表、交易建议（事前/事后/对冲/观望） |

---

## 5. 核心原则

1. 仓位大小由**最紧约束**决定：止损预算、波动率、流动性、集中度、相关性取最小值
2. 对冲改变有效敞口，须与仓位综合考虑
3. 规则先于情绪：冷静时定规则，波动时执行规则
4. 论点必须可证伪——没有能推翻它的证据，就不是论点

---

## 6. 使用要点

- "不对冲 + 小仓位"常优于"大仓位 + 昂贵对冲"
- 止损是纪律问题，不是预测问题
- 事件分析核心是**预期差**，不是事件本身好坏
- 监控规则必须在建仓前写好；财报后 24 小时内更新
