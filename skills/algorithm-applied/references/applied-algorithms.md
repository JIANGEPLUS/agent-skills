# 应用、数值与学习算法

## 数值与约束优化
写清变量、目标、约束、尺度、凸性是否已知；局部最优不等于全局最优。线性/整数模型检查可行性、无界性和求解器状态，不把超时的 incumbent 说成已证最优。
迭代法写初始化、步长、停止准则、容差、最大迭代及失败输出。区分问题条件差与算法不稳定；检查残差和必要的敏感性，不只看输出小数位。
新库接口或收敛结论不确定时核查官方文档/原始论文，不杜撰定理。

## 机器学习、推荐与检索
先定义业务目标、标签、损失和评估指标；给简单基线。训练/验证/测试按时间、实体和泄漏风险合理划分；预处理只在训练集拟合。
调参不接触最终测试集。类别不平衡、漂移、冷启动、采样偏差和在线反馈闭环按任务评估。离线指标提升不等于线上因果效果。
推荐召回/排序分开评估；检索的近似结果报告召回—延迟—内存取舍。训练成本、推理预算、数据权限与复现种子纳入交付。
不自动启动大训练或收费 GPU 作业。用户仅要算法知识时不强行改造成 ML 项目。

## 调度与工程优化
可行解优先满足硬约束；软约束的权重来源要透明。对 NP-hard 等复杂性断言需有可靠依据，不能因为暂时不会就贴标签。
精确求解、近似保证和启发式在输出中分开写。小实例可与穷举对照，大实例报告可行性、界/差距（若能得到）和耗时，不编造最优性。
分布式考虑通信、倾斜、故障与一致性；并行不代表复杂度自动除以机器数。
