# algorithm-applied — 应用、数值与学习算法

---

## 1. 简介

算法技能包的一个模块，负责**数值与约束优化、机器学习/推荐/检索、调度与分布式**这三类工程侧算法。可独立调用，也可由 `algorithm-engineer` 总纲路由而来。

---

## 2. 职责边界

| 做什么 | 不做什么 |
|--------|---------|
| 迭代法与凸优化、线性/整数规划、ML 指标与切分、召回排序与近似检索评估、调度约束与分布式成本 | 经典数据结构与图论题（→ `algorithm-modeling` / `algorithm-domain-checks`）、单元实现与跑分（→ `algorithm-implementation`） |

---

## 3. 触发条件

迭代法收敛与容差、线性整数规划、求解器状态、标签与指标定义、数据泄漏、训练验证切分、召回排序评估、近似检索权衡、调度硬软约束、NP-hard 断言、并行通信与倾斜。

---

## 4. 输入

业务目标与约束描述；可选：数据规模、可用特征、算力预算、已有基线与指标。

---

## 5. 三类工作流

| 类别 | 关键步骤 |
|------|---------|
| 数值与约束优化 | 变量/目标/约束/尺度与凸性 → 检查可行性与求解器状态 → 迭代法写明初始化、步长、停止准则、容差、失败输出 → 检查残差与敏感性 |
| 机器学习 / 推荐 / 检索 | 定义目标、标签、损失与指标 → 给简单基线 → 按时间/实体切分防泄漏，预处理只在训练集拟合 → 调参不碰测试集 → 召回与排序分开评估，检索报告召回—延迟—内存取舍 |
| 调度与工程优化 | 硬约束优先，软约束权重透明 → 精确/近似/启发式分开写 → 小实例与穷举对照，大实例报告可行性与差距 → 分布式计入通信、倾斜、故障与一致性 |

---

## 6. 输出

- 业务目标、指标与基线
- 方案与保证范围（精确 / 近似 / 概率 / 启发式分开写）
- 数据与切分说明、泄漏风险
- 复杂度与资源预算（训练、推理、通信）
- 复现信息（版本、种子、依赖）与残留风险

---

## 7. 使用要点

- 不自动启动大规模训练或收费 GPU 作业
- 用户只要算法知识时不强行改造成 ML 项目；算法工程 ≠ 盲目选择深度学习
- 离线指标提升不等于线上因果效果
- NP-hard 等断言需可靠依据，不因"暂时不会"就贴标签
