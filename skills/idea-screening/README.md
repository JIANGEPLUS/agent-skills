# idea-screening — 选股与创意生成

---

## 1. 简介

股票研究技能包的一个模块，负责**从全市场筛出候选标的**。可独立调用，也可由 `equity-research` 总纲路由而来。

---

## 2. 职责边界

| 做什么 | 不做什么 |
|--------|---------|
| 量化筛选、主题价值链扫描、一页纸想法卡、优先级排序 | 对单一标的做深度分析（→ `fundamentals-analysis` / `valuation`）、写成正式推介（→ `research-report`） |

---

## 3. 触发条件

选股 / 筛选 / stock screen / 找标的 / 投资想法 / idea generation / 主题扫描 / "有什么可看的" / "pitch me something"。

---

## 4. 输入

方向（Long/Short/两者）、市值范围、行业、风格（价值/成长/质量/特殊情形/事件驱动）、地域、主题（可选）。参数缺失时先向用户确认。

---

## 5. 筛选模板

- **价值**：P/E 低于行业中位、EV/EBITDA 低于历史均值、FCF 收益率 >5%、P/B <1.5x、内部人买入、股息率高于市场
- **成长**：收入增速 >15%、盈利增速 >20%、增速加速、利润率扩张、ROIC >15%、SaaS NRR >110%
- **质量**：5 年以上连续增长、ROE >15%、低负债、高 FCF 转化率、内部人持股 >5%
- **做空**：增速放缓、利润率压缩、应收/存货异常、内部人卖出、无理由估值溢价、会计红旗
- **特殊情形**：IPO/SPAC 解禁、12 个月内分拆、重组后公司、积极主义介入、管理层更换

---

## 6. 输出

5-10 个标的的一页纸短名单（指标表 + 3-5 条论点 + 关键风险 + 建议下一步）+ 筛选方法论说明 + 横向对比表 + 优先级排序。

---

## 7. 使用要点

- 筛选产生**候选**，不产生结论——每个标的都要接基本面工作
- 最好的想法常在交集处（因短期逆风而以便宜价格买到的高质量公司）
- 避开拥挤交易；逆向想法必须有催化剂，没有催化的抢跑等同于错误
- 做空需要更高信心：时点更难、风险不对称
