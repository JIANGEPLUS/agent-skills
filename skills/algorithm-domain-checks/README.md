# algorithm-domain-checks — 领域易错前提

---

## 1. 简介

算法技能包的一个模块，负责**在实现前核查图、树、字符串、数论组合、几何等领域的隐含假设与退化情况**，避免模板套错前提。可独立调用，也可由 `algorithm-engineer` 总纲路由而来。

---

## 2. 职责边界

| 做什么 | 不做什么 |
|--------|---------|
| 四大领域的前提核查、退化情况枚举、前提不满足时的替代方案 | 通用建模选型（→ `algorithm-modeling`）、证明与复杂度（→ `algorithm-proof`）、数值优化与机器学习（→ `algorithm-applied`） |

---

## 3. 触发条件

负权/负环最短路、Dijkstra 前提、重边自环、森林与拓扑环、网络流建模、字符串匹配与滚动哈希、取模求逆与乘法溢出、组合计数、几何退化与 epsilon。

---

## 4. 输入

领域与场景描述；可选：输入数据特征（有向性、权重范围、字符集、模数、坐标量级）。

---

## 5. 四块核查清单

| 领域 | 关键核查项 |
|------|-----------|
| 图与树 | 有向性、重边/自环、权重范围、连通与多源；最短路区分非负/负边/负环；树需确认确为树；拓扑处理有向环；网络流明确容量、残量反向边与守恒 |
| 字符串 | 字节/码点/字素簇与规范化语义；线性结论含预处理与输出代价；滚动哈希碰撞风险 |
| 数论与组合 | 模数是否为素数、除法求逆；负数取模与乘法溢出；零/负数/边界阶乘；概率独立性与计数重复 |
| 几何 | 共线、重合、边界点、自交、空集；方向判定溢出与浮点误差；epsilon 不破坏严格弱序；精确谓词 vs 近似坐标 |

---

## 6. 输出

- 领域与场景判定
- 前提核查表（项 / 状态 / 依据）
- 不满足前提时的替代方案
- 遗留待确认项

---

## 7. 使用要点

- 适用条件不满足时换方法，不硬套模板
- 哈希相等不是确定性相等；期望性质不是最坏保证
- 只在需要时加载核查清单，不对每个问题铺开全部条目
