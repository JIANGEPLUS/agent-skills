# 领域易错前提

## 图与树
读取边是否有向、重边/自环、权重范围、是否连通及多源要求。最短路要区分非负边、负边和负环；不把 BFS 当作任意加权图解法。Dijkstra 的常规保证要求非负权；有负边时换适用方法而非悄悄忽略。
树算法先确认确为树；森林处理分量。拓扑序需处理有向环。网络流建模明确容量、残量反向边和守恒，费用模型注意负费用及终止条件。

## 字符串
确定字节、码点或字素簇及规范化/大小写语义。匹配算法的线性结论不能漏掉预处理或大量输出代价。滚动哈希有碰撞风险，需要容错说明或实际比较验证。

## 数论与组合
模数是否为素数、除数能否求逆需核查；负数取模和乘法溢出按语言处理。零、负数、边界阶乘及不可逆情况不可忽略。概率分母、独立性和计数是否重复写明。

## 几何
明确退化情况：共线、重合、边界点、自交与空集合。方向判定注意整数溢出或浮点误差；epsilon 不能任意加入排序比较而破坏严格弱序。区分精确谓词和近似坐标。
